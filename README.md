# Adapta 11

## Resumen ejecutivo

Adapta 11 es un sistema adaptativo para la preparación de las pruebas Saber 11 que utiliza técnicas de inteligencia artificial para personalizar el proceso de aprendizaje de cada estudiante. El proyecto surge como respuesta a las limitaciones de los simulacros tradicionales, los cuales presentan conjuntos de preguntas similares para todos los usuarios sin considerar de manera individual su desempeño, fortalezas, debilidades, áreas de interés u objetivos de puntaje.

La solución propuesta implementa un banco de preguntas para las áreas de **Matemáticas** y **Lectura Crítica**, organizado de acuerdo con las competencias, componentes y niveles de dificultad correspondientes. A partir de este banco, el sistema cuenta con un **seleccionador adaptativo de preguntas** encargado de determinar cuáles ejercicios presentar a cada estudiante.

La selección de preguntas puede realizarse de acuerdo con la intención del estudiante, permitiéndole trabajar un área o competencia específica, o de manera adaptativa a partir de su historial de respuestas y progreso. De esta forma, el sistema puede priorizar aquellos contenidos en los que el estudiante presenta mayores dificultades y ajustar progresivamente el nivel de dificultad de los ejercicios.

Adicionalmente, Adapta 11 registra y analiza el desempeño del estudiante para construir un perfil de aprendizaje que permita realizar un seguimiento de su progreso, identificar fortalezas y debilidades y ofrecer una experiencia de práctica personalizada.

El proyecto contempla el desarrollo de un prototipo funcional que integra un banco estructurado de preguntas, selección adaptativa de ejercicios, perfilamiento del estudiante, retroalimentación explicable y un panel de seguimiento del progreso. Adapta 11 está concebido como una herramienta de apoyo para la preparación del Saber 11 y no pretende reemplazar los mecanismos oficiales de evaluación del ICFES.

## Objetivos

Diseñar e implementar un prototipo de sistema de seguimiento adaptativo para la preparación del Saber 11, basado en técnicas de inteligencia artificial, que seleccione dinámicamente preguntas de un banco estructurado para las áreas de Matemáticas y Lectura Crítica, de acuerdo con el área de interés, el desempeño, las fortalezas, las debilidades y los objetivos de aprendizaje de cada estudiante.

### Específicos

1. Construir y organizar un banco de preguntas para las áreas de **Matemáticas** y **Lectura Crítica**, clasificándolas de acuerdo con los componentes, competencias y niveles de dificultad correspondientes.

2. Diseñar un mecanismo de **selección adaptativa de preguntas** que permita presentar ejercicios de acuerdo con el área o competencia que el estudiante desee trabajar.

3. Diseñar un mecanismo de selección adaptativa que utilice el **historial de respuestas y el progreso del estudiante** para identificar sus fortalezas y debilidades y seleccionar preguntas acordes con sus necesidades de aprendizaje.

4. Implementar un sistema de seguimiento que registre el desempeño del estudiante y permita observar su evolución a lo largo de las sesiones de práctica.

5. Diseñar un sistema de retroalimentación que permita al estudiante comprender sus resultados, identificar los contenidos que requieren mayor atención y orientar sus futuras sesiones de práctica.

## Alcance

El alcance del proyecto contempla el desarrollo de un prototipo funcional que integra un banco estructurado de preguntas, un sistema de selección adaptativa, perfilamiento del estudiante, retroalimentación explicable y un panel de seguimiento del progreso.

El sistema permitirá al estudiante seleccionar un área o competencia específica sobre la cual desea trabajar. De igual manera, podrá utilizar un modo adaptativo en el que la selección de preguntas se realice a partir de su desempeño histórico.

El seleccionador tendrá en cuenta variables como las respuestas anteriores, porcentaje de aciertos, dificultades identificadas, nivel de dificultad de las preguntas y progreso general del estudiante. Con esta información, el sistema podrá priorizar contenidos que requieran refuerzo y ajustar la dificultad de las preguntas presentadas.

El proyecto se enfocará inicialmente en las áreas de **Matemáticas** y **Lectura Crítica** del Saber 11. El banco de preguntas será previamente estructurado y clasificado para facilitar su selección de acuerdo con las necesidades de cada estudiante.

Adapta 11 funcionará como una herramienta de apoyo para la preparación académica y no reemplazará las pruebas oficiales ni los mecanismos de evaluación establecidos por el ICFES.
